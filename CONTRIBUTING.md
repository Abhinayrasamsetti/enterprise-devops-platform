# Contributing

## Welcome

Thank you for contributing to the Enterprise DevOps Platform.

## Branch Strategy

- main
- feature/*
- bugfix/*
- hotfix/*
- docs/*

## Commit Convention

- feat:
- fix:
- docs:
- refactor:
- chore:
- test:

## Pull Requests

- Describe the change
- Link related issues
- Include validation steps
- Update documentation if needed

## Code Standards

- Modular design
- Reusable components
- Infrastructure as Code
- Documentation-first approach

## Terraform

- Run terraform fmt
- Run terraform validate
- Follow module standards

## Documentation

Keep architecture, README, and module documentation up to date.

## Review Checklist

- Code reviewed
- Tests passed
- Documentation updated
- Security considered
